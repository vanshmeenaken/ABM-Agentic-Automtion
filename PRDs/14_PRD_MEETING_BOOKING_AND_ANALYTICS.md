# 14 — Meeting Booking and Analytics

**Phase:** 14  
**Inputs from:** Phase 13 (handoff with meeting_ready flag)  
**Outputs to:** Dashboard (Phase 3), Pipedrive (Phase 4)

---

## 1. Phase purpose
Build meeting booking flow from handoff, meeting brief generation, calendar activity creation, Pipedrive meeting activity, and full campaign/channel/owner performance analytics.

---

## 2. Meeting booking flow
```
Handoff with meeting_ready = True
  → Sales owner proposes meeting slot
  → Meeting brief generated by agent
  → Calendar event created (via owner's calendar integration)
  → Pipedrive meeting activity created
  → Prospect SequenceState updated to completed
  → AuditLog written
```

---

## 3. Meeting brief contents
- Prospect name, title, company, persona tag
- Campaign context and offer
- Full outreach history (M1–M4 + reply)
- Key talking points based on persona
- Suggested opening and discovery questions

---

## 4. Analytics modules
| Module | Metrics |
|--------|---------|
| Campaign performance | Prospects reached, replies, handoffs, meetings, conversion rate |
| Channel performance | Email vs WhatsApp vs LinkedIn — reply rate, open rate, bounce rate |
| Owner performance | Handoffs assigned, responded, meetings booked, pipeline created |
| Sequence performance | M1–M4 open/reply/stop rates per stage |
| Conversion funnel | Prospect → reached → replied → handoff → meeting → opportunity |

---

## 5. Acceptance criteria
- [ ] Meeting brief auto-generated from handoff data
- [ ] Pipedrive meeting activity created on booking
- [ ] Dashboard shows real-time campaign + channel + owner metrics
- [ ] Sequence funnel shows M1–M4 conversion at each stage
- [ ] All analytics read-only (no platform state changes from analytics layer)
