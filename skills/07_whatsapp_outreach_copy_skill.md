# Skill: WhatsApp Outreach Copy

**Used by:** WhatsApp Copy Agent  
**Domain:** B2B WhatsApp copywriting for M1–M4 sequences

---

## Purpose
Provides format rules, stage guidance, opt-out requirements, and tone standards for B2B WhatsApp outreach messages.

---

## When to use
When WhatsApp Copy Agent generates any WhatsApp message draft.

---

## Stage format guidance

### M1 — Introduction
- Max 120 words
- Open with name personalisation
- One clear context line (why you're reaching out)
- One value proposition line
- One question or CTA
- Opt-out line at end

### M2 — Follow-up
- Max 100 words
- Reference M1 briefly ("Following my note last week")
- One new angle or proof point
- Soft CTA (reply with yes/no)

### M3 — Value add
- Max 90 words
- Lead with a data point or insight
- Connect to their likely business context
- CTA: offer a report, article, or quick call

### M4 — Final
- Max 70 words
- Acknowledge it's the last message
- Leave door open without pressure
- Clean exit CTA

---

## Opt-out requirement
Every WhatsApp message must end with: "Reply STOP to opt out."
This line is mandatory. Compliance Review Agent will BLOCK any WhatsApp message without it.

---

## Tone guidance
| Persona | WhatsApp tone |
|---------|--------------|
| CXO / Strategy | Professional, brief, direct |
| Marketing | Conversational, insight-led |
| Operations | Data-forward, efficiency-focused |
| Product / R&D | Curious, innovation-angle |
| Investor | Data-led, market-signal focused |
| Procurement | Direct, benchmark-led |

---

## Rules
- Never replicate email copy verbatim — WhatsApp must read as WhatsApp
- No formal letter structure ("Dear Sir/Madam", "I hope this email finds you well")
- No HTML, hyperlinks in body (URLs only if necessary)
- Max 300 words total across all fields

---

## Failure cases
- Message reads like an email → rewrite for conversational format
- Missing opt-out line → Compliance Review Agent blocks automatically
- Over 300 words → trim before compliance review
