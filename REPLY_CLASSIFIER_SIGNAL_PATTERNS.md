## Classification Rules (TL;DR)

```
if contains(bounce_signals) → BOUNCE
else if contains(meeting_signals) → MEETING REQUEST
else if contains(negative_signals) → NEGATIVE
else if contains(ooo_signals) → OUT OF OFFICE
else if contains(question_signals) → QUESTION
else if contains(interest_signals) → POSITIVE INTEREST
else → AMBIGUOUS
```
