# Quality Checklist — 14-Item Verification

Learned through testing all three agents. All items must PASS before copy is production-ready.

---

## Full Checklist (All Agents)

- [ ] **M1 opens with specific hook** (pain point OR competitive threat) — no generic angles
  - ✓ "Most leaders at your level aren't tracking dealer consolidation"
  - ✗ "We wanted to reach out with an opportunity"

- [ ] **M1 has specific timeframe** (30-min, 1-hour, 15 minutes) — never just "call"
  - ✓ "Would you be open to a 30-minute call?"
  - ✗ "Would you be open to connecting?"

- [ ] **M1 has value exchange** ("we X, you tell us if Y") — not one-sided pitch
  - ✓ "We walk you through what we found, and you tell us if it maps to your situation"
  - ✗ "We'd like to tell you about our findings"

- [ ] **M2 includes proof reference** (sample, attachment, research findings) — not just "more details"
  - ✓ "Sample attached shows dealer NPS pattern and how top performers are repositioning"
  - ✗ "We have more information we'd like to share"

- [ ] **M2 has soft ask** (no pressure, low intensity) — not pushy follow-up
  - ✓ "Let me know once you've had a chance to review"
  - ✗ "Looking forward to your response"

- [ ] **M3 uses "Either way" opener** (low-pressure pattern)
  - ✓ "Either way, let's connect once..."
  - ✗ "I wanted to follow up on my previous email..."

- [ ] **M3 escalates with secondary pain** + urgency (shows consequence, not just repetition)
  - ✓ "Margin compression is accelerating — companies ahead already moving"
  - ✗ "Dealer consolidation continues to be an issue"

- [ ] **All CTAs name specific timeframe** (30-min, 1-hour, 15 minutes, etc.)
  - ✓ All CTAs (M1, M2, M3) specify duration
  - ✗ Any CTA says "call" or "connect" without timeframe

- [ ] **No forbidden language** (compare notes, quick chat, let me know, happy to connect, worth a call)
  - ✓ Uses alternatives: walked competitors, companies ahead, worth 30 minutes to align
  - ✗ Any forbidden phrase appears in full text

- [ ] **Follow-ups included** (Email: M1-M3 soft asks, LinkedIn/WhatsApp: dedicated follow-up messages)
  - ✓ Email M2-M3 have follow-up language built in; LinkedIn/WhatsApp have separate follow-up messages
  - ✗ Any message lacks follow-up or soft ask

- [ ] **Conversational tone** (appropriate to channel — professional for Email, peer for LinkedIn, urgent for WhatsApp)
  - ✓ Email: professional + research credibility; LinkedIn: peer-to-peer; WhatsApp: conversational + urgent
  - ✗ All three sound identical; or any sounds robotic/corporate

- [ ] **Personalizations present** (prospect first name, company name, industry, region where applicable)
  - ✓ [first_name], [Company], [Industry], [Region] correctly filled
  - ✗ Any [bracket] placeholder remains in final message

- [ ] **Word counts in range**
  - Email: 100-150 words per message
  - LinkedIn: 80-120 (M1), 60-80 (M2), 80-100 (M3)
  - WhatsApp: 25-40 words per bubble
  - ✓ All messages meet target ranges
  - ✗ Any message over/under by >20%

- [ ] **Campaign type-specific framing applied** (Survey/POV/Benchmarking/Competition Benchmarking/Market Research)
  - ✓ M1 opener matches campaign framing (mandate/intelligence/research/analysis/trends)
  - ✗ Generic opening that doesn't signal campaign type

---

## Check-By-Channel

### Email Specific

- [ ] Subject line is unique (M1) or "Re:" threaded (M2-M3)
- [ ] Preview text under 100 characters
- [ ] Paragraph breaks present (mobile readability)
- [ ] Uses "walked competitors through" (not "peer")
- [ ] Opening: "We recently finished a mandate/intelligence on [Industry]"

### LinkedIn Specific

- [ ] Short, punchy lines (no dashes, use line breaks)
- [ ] Conversational tone ("Hi [name], [insight]")
- [ ] "Either way" pattern for M3
- [ ] One idea per paragraph
- [ ] Reference their planning cycle/season where possible
- [ ] Post-connection DMs only (no connection request note)

### WhatsApp Specific

- [ ] No ALL CAPS or excessive punctuation
- [ ] No emojis (keep professional)
- [ ] Line breaks instead of dashes
- [ ] One message bubble = one idea
- [ ] Quick CTAs ("30-min call", "hour", "review findings")
- [ ] Follow-ups: M1 has 2, M2 has 1, M3 has none

---

## Pain Point Quality

- [ ] Primary pain point is specific, not generic
  - ✓ "Dealer NPS declining as consolidation shifts power"
  - ✗ "Market challenges in the sector"

- [ ] Secondary pain point (M3) escalates or shows consequence
  - ✓ "Margin compression accelerating"
  - ✗ "More consolidation expected"

- [ ] Pain points include industry context
  - ✓ "Private label penetration across regions"
  - ✗ "Price competition"

---

## CTA Quality

- [ ] M1 CTA: specific time + value exchange + context reference
- [ ] M2 CTA: soft ask with no pressure
- [ ] M3 CTA: Either way opener + escalation + timeframe
- [ ] No timeframe-less CTAs anywhere
- [ ] No value-exchange-less CTAs anywhere

---

## Verification Workflow

**Before declaring production-ready:**

1. Read full M1-M3 series out loud
2. Check every CTA has timeframe + value exchange + context
3. Scan for forbidden words
4. Verify personalizations filled
5. Count words per message
6. Confirm "Either way" in M3
7. Check tone matches channel
8. Verify no generic language
9. Confirm follow-ups present
10. Read against full checklist above

**If any item fails:** Mark as "Needs Revision" and identify specific fix.

**If all items pass:** Mark as "APPROVED — Ready for API layer".

---

## Common Failures & Fixes

| Failure | Example | Fix |
|---------|---------|-----|
| Generic pain | "Market challenges" | Add industry + consequence: "Dealer consolidation creating NPS pressure" |
| No timeframe | "Would you be open to a call?" | Add specific: "Would you be open to a 30-minute call?" |
| No value exchange | "We'd love to share our findings" | Add exchange: "We walk through findings, you tell us if it maps to your situation" |
| Forbidden word | "Worth a quick chat?" | Replace: "Worth a 30-minute call to explore?" |
| Generic angle | "Opportunity in your sector" | Add specificity: "Margin compression from bundled solutions" |
| Missing context | "Your company" (generic) | Reference specific: "Your scale in India" or "Your H1 planning" |
| No Either way M3 | M3 starts with "I wanted to follow up" | Rewrite: "Either way, let's connect. Margin acceleration means..." |
| Weak follow-up | "Looking forward to your response" | Use soft ask: "No pressure — just thought this mapped to your situation" |
